**Documento 5: `helena-linguagem-de-compra.md`**

Frontmatter igual ao padrão.

Cabeçalho de contexto logo abaixo do frontmatter:
```
> Quando a cliente usa essas frases ou comportamentos, está se aproximando da decisão.
> A janela dura 3-5 minutos. Aja imediatamente — proponha próximo passo concreto com data.
```

Estrutura:
- `## Sobre Este Documento` — contexto + frase-chave
- `## Frases Diretas de Comprometimento` — pelo menos 6 frases reais com `→ O que fazer:` após cada uma:
  - "Tá bom, eu acredito que dá." → fechar imediatamente: "Ótimo. Então o próximo passo é..."
  - "Eu vou fazer isso. Vou começar amanhã." → cliente assumiu autoria. Propor data + entregável concreto.
  - "Agendado para quinta-feira, 26, às 15h30." → especificidade = compromisso real. Confirmar e registrar.
  - "Vou compartilhar um álbum no iCloud com você." → ação concreta = sinal forte. Acompanhar imediatamente.
  - "Quando eu começar..." → futuro concreto. Ancora: "Então vamos combinar que você começa em [data]."
  - "Quando eu lançar..." → está se vendo no resultado. Reforçar com próximo passo.
- `## Mudança de Linguagem` — 3 padrões de transição: "de perguntar 'devo?' → 'como?'", "de defender a situação atual → ser dona do problema", "de falar no presente sobre dificuldades → falar no futuro sobre resultados"
- `## Sinais Comportamentais` — pelo menos 6 comportamentos com `→ O que fazer:` após cada um:
  - Compartilha vulnerabilidade pessoal → baixou a guarda. Não pressionar. Validar e propor próximo passo suave.
  - Volta após interrupção → comprometida com a conversa. Retomar exatamente onde parou.
  - Pergunta sobre escala/contratação → já assumiu que vai comprar. Responder com entusiasmo + roadmap.
  - Valida o diagnóstico: "Sim, é exatamente isso." → janela aberta. Fechar com plano concreto.
  - Faz pergunta sobre implementação → está visualizando. Dar passo a passo detalhado.
  - Pergunta sobre preço ou parcelamento → interesse real. Apresentar opções sem hesitar.
- `## Regra dos 3-5 Minutos` — bloco de aviso: "A janela de decisão dura 3-5 minutos após o sinal. Depois disso a cliente reconstrói as defesas. Se não agir nesse momento, o fechamento se perde."

Conteúdo baseado em: "Sinais de Fechamento" + "Os Três Momentos de Fechamento" da fonte primária.

**Documento 6: `helena-linguagem-de-fuga.md`**

Frontmatter igual ao padrão.

Cabeçalho de contexto:
```
> Esses sinais indicam que a cliente está recuando. Não responda o sintoma — redirecione para a causa real.
> Regra: nunca confronte a esquiva diretamente. Use validação + redirecionamento.
```

Estrutura:
- `## Sobre Este Documento` — contexto + frase-chave
- `## Sinais de Adiamento` — pelo menos 4 frases com `→ Redirecionamento:` após cada uma:
  - "Talvez quando eu tiver mais tempo..." → "Entendo. Pode me contar como está sua semana hoje?"
  - "Quando eu tiver menos trabalho..." → "O que precisaria mudar para isso ser o momento certo?"
  - "Depois a gente vê isso." → "Claro. Para eu entender melhor — o que está impedindo agora?"
  - "Eu vou tentar..." (vs. "eu vou fazer") → sinal de baixo comprometimento. Validar e pedir clareza: "O que te dá mais insegurança sobre fazer isso?"
- `## Hipotéticos como Barreira` — pelo menos 3 frases com redirecionamento:
  - "O que se ninguém gostar?" → não responder o hipotético. "É normal ter essa dúvida. O que te faz achar que pode não funcionar pra você?"
  - "E se não funcionar pra mim?" → "O que seria funcionar para você? Como você mediria isso?"
  - "Preciso ter certeza antes de começar." → "Faz sentido. O que te daria essa certeza?"
- `## Externalização` — 3 padrões com redirecionamento:
  - "Não tenho dinheiro agora." (sem interesse em negociar) → distinguir de objeção real de preço. Perguntar: "Se o investimento não fosse o problema, o que te impediria?"
  - "Eu faço tudo, isso é horrível." (sem pergunta de solução) → "Qual dessas tarefas você mais odeia fazer?" — direcionar para o sistema.
  - "É porque eu sou assim mesmo." → crença limitante como identidade. Validar + desafiar suavemente: "Muitas das minhas clientes diziam o mesmo. O que mudou para elas foi..."
- `## Minimização` — 3 padrões com redirecionamento:
  - "Fica raso." → perguntar qual aspecto parece raso e explorar com curiosidade, não defesa.
  - "Não tem uma história grande por trás." → "O que para você seria uma história grande?" — reframing de autoridade.
  - "Acho que não tô dando conta." → "O que especificamente não está saindo como você quer?" — separar percepção de realidade.
- `## Regra de Ouro` — "Nunca confronte a esquiva diretamente. Cada sinal de fuga é uma pergunta disfarçada. Sua tarefa é descobrir a pergunta real."

Conteúdo baseado em: "Sinais de Fuga" da fonte primária + expansão dos redirecionamentos.
