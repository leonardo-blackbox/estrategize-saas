    - Parameter: `sessionId: string | null`
    - When sessionId is null or falsy, return empty state (no connection)
    - Build SSE URL: `${VITE_API_URL}/api/meetings/${sessionId}/helena?token=${token}` — get VITE_API_URL from `import.meta.env.VITE_API_URL as string || 'http://localhost:3001'`; get token via `useAuthStore.getState().session?.access_token`
    - Create EventSource in useEffect; listen for `message` event; parse `JSON.parse(event.data)` as HelenaReport
    - Prepend new reports to state array (newest first), cap at 10 items
    - Auto-reconnect: on `error` event, set `connected=false`, close current source, schedule reconnect with `setTimeout(connect, 3000)` — max 5 retries tracked with a ref; reset retry count on successful message
    - Cleanup: close EventSource and clear timeout on unmount or when sessionId changes
    - Track `unreadCount: number` — increment on each new report; reset when caller calls `markAllRead()`
    - Returns: `{ reports: HelenaReport[], connected: boolean, unreadCount: number, markAllRead: () => void }`
    - Hook file must stay ≤120 lines
